# Teacher CV Manager

Teacher CV Manager es una aplicación web para gestionar los currículums de los profesores. Permite agregar, editar, ver y eliminar CVs, así como buscar entre los CVs existentes.

## Tecnologías Utilizadas

- React
- TypeScript
- Tailwind CSS
- Vite
- React Router
- React Hook Form
- Lucide React

## Instalación y Ejecución

Sigue estos pasos para instalar y ejecutar el proyecto en tu entorno local:

1. Clona el repositori.
2. Instala las dependencias.
- npm install
3. Ejecuta el servidor de desarrollo:
-npm run dev
4. Abre tu navegador y navega a http://localhost:3000 para ver la aplicación en funcionamiento.
--Scripts Disponibles
-npm run dev: Inicia el servidor de desarrollo.
-npm run build: Construye la aplicación para producción.
-npm run preview: Previsualiza la aplicación construida.
-npm run lint: Ejecuta el linter para verificar el código.
